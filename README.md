# DREADING online multiplayer

Open the GitHub Pages site, choose Host and play or Set up a match to watch, and share the room invitations. Two commanders plus spectators connect with PeerJS/WebRTC. Commander 1 runs the match simulation in their browser and must stay connected. No local server program is needed.

Only the online runtime and required assets are published. Local editors, tools, backups, tests and older maps are excluded. Map geometry is gzip compressed for download and decompressed once on load; rendered geometry and textures are unchanged.

Third-party notices remain with the assets.
