# DREADING online multiplayer

Open the GitHub Pages site, choose Host and play or Set up a match to watch, and share the room invitations. 1v1 or 2v2 plus spectators connect with PeerJS/WebRTC. In 2v2 each team shares an army and credits; players control separate soldiers. The Blue host runs the simulation and must stay connected. All commanders must be connected for the match to run. No local server program is needed.

Only the online runtime and required assets are published. Local editors, tools, backups, tests and older maps are excluded. Map geometry is gzip compressed for download and decompressed once on load; rendered geometry and textures are unchanged.

Third-party notices remain with the assets.
